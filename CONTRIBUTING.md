# Contributing

Contributions are welcome. Please include focused tests with every behavior
change and keep changes compatible with Shopware 6.7 on PHP 8.2 or newer.
Run `bin/check` and `bin/integration` before releasing a change. Test the
release ZIP in a disposable Shopware project.

New releases follow the current stable Shopware major line. Older plugin tags
remain installable, but are no longer maintained. Never change an existing tag.
